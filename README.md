# UAB Email Signature Builder

Standalone HTML tool for creating a UAB-formatted email signature with:

- live preview
- copyable HTML output
- plain-text fallback
- installation guidance for Outlook, Apple Mail, and mobile

## Files

- `index.html`: the complete app

## Deploy

This project is static. Deploy `index.html` on any static host, including:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

## Local Use

Open `index.html` directly in a browser.
