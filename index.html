Install And Configure

Choose the client your users are configuring. The steps below are tailored to the builder output and include default-signature guidance where the client supports it.

Outlook for Windows

  1. Click Copy signature HTML in this tool.
  2. In Outlook, go to File > Options > Mail > Signatures.
  3. Select New, give the signature a clear name such as “UAB Official.”
  4. Paste into the signature editor. If the formatting looks odd on first paste, click once outside the block and let Outlook finish rendering it.
  5. Use the “Choose default signature” dropdowns to apply it to new messages and replies/forwards if desired.
  6. Send a test message to yourself and confirm spacing, links, and line breaks.

Outlook for Mac

  1. Copy the HTML from this builder.
  2. Open Outlook > Settings > Signatures.
  3. Create a new signature and paste into the editor.
  4. Assign it to the correct account and choose whether it should be used for new messages and replies.
  5. Send a test email to verify Outlook preserved the contact links and spacing.

Outlook on the Web or New Outlook

  1. Copy the signature HTML.
  2. Go to Settings > Account > Signatures.
  3. Click Add Signature.
  4. Enter a name for the signature on the first line.
  5. Paste the copied HTML into the editor box below the signature name.
  6. Set the options for default for new messages and default for replies and forwards.
  7. Save, then send a message to yourself and review it in both desktop and mobile views.

Apple Mail

  1. Copy the signature HTML.
  2. Open Mail > Settings > Signatures.
  3. Choose the correct account, create a new signature, and paste into the signature area.
  4. If Apple Mail restyles the block, remove extra formatting in the editor and paste again.
  5. Attach the signature to the correct account and test by sending to a desktop and mobile inbox.

iPhone, iPad, and Android

  1. Most native mobile mail apps do not preserve rich HTML signatures consistently.
  2. Use Copy plain text and paste the fallback into the mobile signature setting if your device only supports plain text.
  3. If your users primarily send from the Outlook mobile app, keep the desktop or web signature as the primary version and test whether the app syncs it as expected for their account.
  4. After setup, send a message from the phone to confirm line breaks and contact labels remain readable.

What This Tool Enforces

The generator is based on the current UAB brand guide page for email signatures and keeps the editable surface focused on the fields users actually need.

  • Signature markup uses a Calibri-first font stack and a fixed 12 pt rendering target to stay within the published guidance.
  • The builder requires only the `Name | Title` line and the `UAB Medicine | Heersink School of Medicine` line.
  • The name and title can render in UAB green or black. The current template uses green.
  • Contact labels support the guide’s recommended style such as P, O, M, and F.
  • Blank fields are removed from the final output so users do not have to manually clean up separators or empty lines.
  • The builder includes a plain text fallback for mobile clients that strip HTML formatting.
